# Patent notice and non-assertion commitment

## Status

A United States patent application relating to sparse internal control of
language models, including methods described in this repository, has been filed
by Xizhe Zhang (the "Applicant"). The application is pending. Nothing in this
repository is a statement about the scope of any claim that may issue.

## Commitment for the six-axis evaluation protocol

The Applicant commits not to assert any claim of the pending application, or of
any patent issuing from it or claiming priority to it, against any person or
organization for making, using, selling, offering for sale, importing, or
distributing an implementation of the six-axis control-evaluation protocol
(reachability, signed reversal, dose response, feedback controllability,
off-target preservation, held-out reuse) as described in the paper *Sparse
Internal Control of Language Models* and its published protocol specification.
This includes independent implementations that do not use the code in this
repository.

This commitment is irrevocable, worldwide, and royalty-free, and it binds the
Applicant's successors and assignees. It terminates with respect to any party
that files, maintains, or voluntarily joins a claim alleging that an
implementation of the protocol, or this repository, infringes a patent held by
that party.

The code in this repository is licensed under the Apache License, Version 2.0.

## Scope

The commitment above covers the evaluation protocol. It does not by itself
extend to other claimed subject matter, such as the driver-selection methods
(Driver-OMP, Coverage-Driver and related procedures), when those are practiced
outside the Apache-licensed code of this repository.
